# Programa de Gestión de Datos de Calificaciones

Este es un programa simple en Python que permite realizar varias operaciones con calificaciones de estudiantes.

## Funcionalidades

El programa ofrece las siguientes opciones:

1.  **Determinar estado de aprobación:** Ingresa la calificación de un estudiante y te dice si aprobó o no (considerando 70 como la nota mínima para aprobar).
2.  **Calcular promedio de notas ingresadas:** Ingresa una lista de calificaciones separadas por comas y calcula el promedio.
3.  **Contar cuántas calificaciones son mayores a un valor específico ingresado:** Después de ingresar una lista de notas, puedes ingresar un valor y el programa te dirá cuántas de las notas son mayores que ese valor.
4.  **Contar cuántas veces se repite una calificación específica ingresada por el usuario:** Después de ingresar una lista de notas, puedes ingresar una calificación y el programa te dirá cuántas veces aparece en la lista.
5.  **Salir:** Termina la ejecución del programa.

## Cómo usarlo

1.  Guarda el código Python en un archivo (por ejemplo, `gestion_calificaciones.py`).
2.  Abre una terminal o símbolo del sistema.
3.  Navega hasta el directorio donde guardaste el archivo.
4.  Ejecuta el programa con el comando: `python gestion_calificaciones.py`
5.  Sigue las instrucciones del menú para elegir la acción que deseas realizar.
